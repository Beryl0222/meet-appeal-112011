# 团体赛仲裁桌交接记录

赛事登记组交接签字单、双语赛务来件与公告归入关系。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/signoff.json` 保存id、项目、场地、队伍、场次、名单、签署。名单顺序与单场顺序分别属于不同记录；时间为赛场当地时间。

- `data/roster.json` 保存id、姓名、英文、队伍、项目。姓名和英文转写可能重名，以登记号为个体标识。

- `data/links.json` 保存id、签字单、汇总、说明。裁判台公布的归入关系。

- `data/messages.json` 保存id、队伍、时间、来件、引用、内容。引用为收到的邮件或口译记录编号，空表示另起一封。

- `data/bulletins.json` 保存id、内容。本场合成规则与裁判签发记载。

- `data/decisions.json` 保存id、时间、队伍、签字单、原来件、业务动作、内容。仲裁桌签发和裁定来件原话。原签字单不会随处置重录。原来件编号为空表示该动作不依赖某一电子申诉。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus messages --id M1
python3 -m unittest discover -s tests -v
```

## 仲裁记录工具（arbiter 包）

在不改写任何原件的前提下，把双语来件解析为带业务解读的说法与争点，按公告 R1–R6
计算时限、暂缓范围与裁定影响。原件始终只读，登记更正只作为裁定 overlay 另行记录。

### 业务规则落点

- **动作识别**：每封来件切分为若干说法，分别判定申诉、补证、咨询、撤回；否定句
  （“not contesting the team total”）独立成组，只登记排除范围，不构成争点。
- **争点对象**：区分上场资格、名单录入、单场记录、团体汇总；二次口译不自行建案，
  只作为同线程候选读法，须经复核员逐句确认，不能用一次整封确认替所有争点背书。
- **匹配不上签字单**：保留候选单据、原话与原始收到时间，不猜测硬绑、不停止签发。
- **时限**：名单申诉自团体登记签字起 20 分钟，单场结果自该场签字起 15 分钟；
  澄清原争点沿用首次有效提出时间，另一场/另一对象的新争点单独计时，届满即未受理。
- **条件性声明**：先列“待核条件”软暂缓，条件核明后按原始收到时间回溯判断（R5）。
- **暂缓范围**：名单争点只保留可能引用被争名字的分项及其团体汇总（R2）；一个分项
  可并存多条争点，任一未决即保留限制；未受理争点不停止签发（R3），别队单据不卷入。
- **复核处置**：接受登记更正（逐编号指名单据）、维持原记录、驳回、记录撤回，
  分别记录对分项、关联汇总和复核截止期的影响。
- **回执**：只列本队争点与裁定依据，保留原文/译文对应，不披露别队内部材料（R6）。

### 命令行

隔离模式下直接运行入口脚本（解释器自动把脚本目录加入路径）：

```text
python3 -I arbiter/cli.py claims                 # 全部争点、时限与状态
python3 -I arbiter/cli.py held                   # 暂缓/照常签发与团体汇总状态
python3 -I arbiter/cli.py held --at 10:20        # 还原历史时刻的暂缓范围
python3 -I arbiter/cli.py receipt 北队           # 队伍回执（只含本队材料）
python3 -I arbiter/cli.py audit                  # 工作人员审计轨迹与状态时间线
python3 -I arbiter/cli.py rules                  # 仲裁规则与解析出的时限
python3 -I arbiter/cli.py decide 维持 I3 10:45 --reason "维持二场原记载"
python3 -I arbiter/cli.py decide 更正 I1 11:00 --sheets S10,S12 --reason "更正重复登记"
```

加 `--json`（位于子命令前）输出结构化 JSON，例如
`python3 -I arbiter/cli.py --json held --at 10:20`。

### 模块结构

```text
arbiter/
  model.py      领域模型：说法、对象指向、争点、状态时间线、暂缓项
  timeutils.py  赛场时间与中文时限/序号解析
  parse.py      双语标记驱动的分句、动作/否定/条件/引述/对象识别
  resolver.py   说法到签字单、登记号、团体汇总的绑定与候选保留
  board.py      建案、时限、暂缓、逐句确认、复核处置、回执与审计
  cli.py        命令行入口
```
