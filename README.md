# 团体赛仲裁桌交接记录

赛事登记组交接签字单、双语赛务来件与公告归入关系。
演练资料使用虚构单位、人员与业务文字。资料以 UTF-8 JSON 给出，各文件按收到的顺序保存，正文中引述的名字和词形按原样保留。

## 资料格式

每份资料是记录数组。编号的作用范围是所在资料集，同一业务对象如有不同版本则另列记录。空字符串表示交接文件未填写，空数组表示未列条目。没填写的值无法代替明确的反面事实。

- `data/signoff.json` 保存id、项目、场地、队伍、场次、名单、签署。名单顺序与单场顺序分别属于不同记录；时间为赛场当地时间。

- `data/roster.json` 保存id、姓名、英文、队伍、项目。姓名和英文转写可能重名，以登记号为个体标识。

- `data/links.json` 保存id、签字单、汇总、说明。裁判台公布的归入关系。

- `data/messages.json` 保存id、队伍、时间、来件、引用、内容。引用为收到的邮件或口译记录编号，空表示另起一封。

- `data/bulletins.json` 保存id、内容。本场合成规则与裁判签发记载。

## 阅读与运行

使用 Python 3.11.2 和标准库，无需安装第三方包。在仓库根目录可列出交接资料，或查看一条原始记录的所有版本。测试核查文本能原样读取和资料之间的关联。

```text
python3 -m corpus
python3 -m corpus messages --id M1
python3 -m unittest discover -s tests -v
```
